# WINDRISE — 2D Side-Scroll Action RPG Vertical Slice v0.5

완전히 신규로 시작한 2D 횡스크롤 액션 어드벤처 RPG 프로토타입입니다. 기존 Puppy Maker/V18 프로젝트와 코드를 공유하지 않습니다.

## v0.5 핵심 변화

- 상층 폐허를 짧은 보상 방에서 약 4,500px 길이의 독립 탐험 루트로 확장
- Air Dash 없이는 안정적으로 건너기 어려운 두 개의 실제 낙하 간격
- 낙하 시 최근 바람 표식으로 복귀하는 짧은 실패 루프
- 상층 폐허 전용 비행 적 `Wind Raptor` 4마리 및 Dive Attack AI
- 비행 적 전용 공중 Telegraph / 체력 / 피격 / Stagger 처리
- 바람의 잔향 3개 수집 + 상층 거점 도달 목표
- 상층 폐허 진행도 HUD와 잔향 카운터
- 바람의 검사 기억의 전투 변화: 3연격 마지막 타격이 원거리 바람 검기를 방출
- 바람 검기는 공중 적을 견제하고 경직시킬 수 있음
- 새 상층 폐허 비주얼 콘셉트 이미지를 레퍼런스 에셋으로 포함

## 현재 플레이 루프

초원 탐험 → 폐허의 기사 → 처형 → 무너진 신전 → 바람의 검사 기억 → Air Dash 해금 → 초원 재탐험 → 봉인된 상층 길 개방 → 상층 폐허 → 두 개의 Air Dash 간격 → 비행 적 전투 → 잔향 3개 수집 → 상층 거점 확보

## 조작

- A / D: 이동
- Space: 점프
- Shift: 지상 회피 / 공중 Air Dash
- J: 3연격 / Perfect Dodge Counter
- K: 강공격
- Q: 패링
- E: 처형 / 제단 / 기억 조각 / 지역 상호작용
